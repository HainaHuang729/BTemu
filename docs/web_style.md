# Signal Atlas style for BTemu

The BTemu progress dashboard uses the visual language of the existing [repaired MCMC results](https://hainahuang729.github.io/21cmTB/joint-repaired.html): warm grey surfaces, orange emphasis, fine borders, numbered navigation, technical labels, large display typography, and square cyan progress panels. The compact scientific overview follows the original Atlas diagnostic-page layout; no simulator field visualization is implied.

EN/中文 switches both static and data-derived text and persists the chosen language locally. A self-hosted Noto Sans SC subset under the included OFL license prevents missing Chinese glyphs on systems without CJK fonts. Font provenance and checksum are recorded in site/fonts/btemu-sc.json.

The scientific data snapshot, classifier threshold, validation populations, reference native and acceptance status are unchanged. All counts remain qualified-wave snapshots rather than live scheduler measurements. Deployment still publishes only site/.

Browser verification covers desktop and mobile layouts, locale switching and persistence, unchanged counts, stable model/resource tables, horizontal overflow, and JavaScript exceptions. Rendering checks do not establish scientific model accuracy.

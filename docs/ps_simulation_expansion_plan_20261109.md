# PS 模拟扩样与训练计划

目标是训练 BTemu 的 10 维球平均 21 cm 功率谱 emulator。现有混合模型用 2,326 个子盒谱训练，在 108 个独立子盒谱测试点上，低红移 RMSE 为 0.445 dex。这个结果作为旧模型基线。下一批训练与验证统一使用全盒谱。

## 模拟与标签

- 使用 \(x_i\) 的冻结 21cmFAST 编译件，二进制 SHA-256 为 `3211a6629109da7379694a9fefeb685b93b71d225f7fdf54120818a94e5702b2`。
- 使用 250 Mpc 全盒，`DIM=512`、`HII_DIM=128`。沿用已核对的 BT 参数映射、背景宇宙学和物理开关。保持自旋温度涨落开启。
- 从同一全盒亮温场扣除盒均值后计算球平均 \(\Delta^2_{21}(k,z)\)。锁定全盒估计器的 FFT 归一化、分箱与插值规则。训练使用 pilot 原有的 9 个红移和 20 个波数，另保存原生全盒谱以供核查。
- 每条产物记录设计 ID、10 维参数、IC 种子、实际载入的编译件哈希、物理配置、谱网格、运行状态和用时。新训练点每点一个独立 IC。

## 批次与选点

| 用途 | 第一批 | 第二批 | 合计 |
|---|---:|---:|---:|
| 广覆盖训练点 | 64 | 192 | 256 |
| 推断相关训练点 | 32 | 96 | 128 |
| 薄弱区域与边界训练点 | 32 | 96 | 128 |
| 新训练点合计 | 128 | 384 | 512 |
| 旧数据配对点 | 32 | 0 | 32 |
| 独立验证点 | 先跑冻结清单中的一部分 | 完成剩余验证点 | 64 |

- **广覆盖**从 \(x_i\) 已有 Sobol 设计中选尚无 PS 标签的点，保持 10 维覆盖。
- **推断相关**用现有 8D 链指引选点，并覆盖 X 射线参数范围。训练设计与推断先验分别定义。
- **薄弱区域和边界**覆盖低 \(k_p\)、高 \(m_s\) 以及其他高误差区域，在这些区域同时变化天体物理参数。\(m_s<1.5\) 先核对 pilot 的筛选条件，再用少量探针确认模拟与标签有效性，之后决定是否纳入扩样。
- **配对**从已有训练点选 32 个，覆盖广域、低红移高误差和边界。沿用各点原 IC 种子，比较同一实现的全盒与子盒谱。每点至少配对一个已有 IC，记录所选种子。
- **验证**提前冻结 64 个独立参数点，覆盖全域、推断相关区域和边界，每点 4 个独立 IC。用四个 IC 的平均全盒谱评估模型，用点内散布衡量 IC 变化。按参数组合隔离训练、配对和验证，833 保留为诊断点。

按每个配对点复算一个 IC 计，完整计划包含 **800 次模拟实现**，即 512 次训练、32 次配对和 256 次验证。按首批完整九红移作业实测核算后续成本。

## 启动与续跑条件

1. 冻结首批 128 个新训练点、32 个配对点和独立验证清单。先提交这 160 个训练与配对作业，同步启动首批独立验证。
2. 对照配对谱，按红移与波数检查全盒和子盒标签差异。用相同全盒训练点比较两种模型训练方式，一种从头训练，另一种先用旧子盒数据预训练再用全盒数据微调。两版使用相同全盒验证点、指标和评估网格。
3. 报告 \(z=6.34,7.10,7.97\) 的低 \(k\) 残差、误差第 90 百分位及误差最高的 10% 参数点，并与同点 IC 散布对照。根据首批的误差分布与运行成本，确定其余 384 个训练点的具体加密位置。
4. 生产前冻结最终模型与全盒评估结果。旧 108 点基准继续用于子盒模型对照，全盒标签以新独立验证集评估。

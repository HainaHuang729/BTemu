# PRD：BT-21cm 论文（2026-10-29，同步核验版）

作者：HNHuang。状态：已有 v0.2 初稿。关联：[PLAN_20261029.md](PLAN_20261029.md)、[RESULTS_20261029.md](RESULTS_20261029.md)。

## 1. 论文目标

研究 BT 修正模型对再电离历史及相关观测拟合的影响，并将 BTemu 作为历史预测工具纳入推断方法。初稿区分物理模型、模拟器误差、初始条件散布和参数采样结果。

## 3. 当前可陈述的结果

1. 65k milestone 的绝对轨迹 RMSE 中位为 0.0010，q95 为 0.0101；xHI(5.9) 和 τ 的绝对误差 q90 分别为 0.0079、0.00070。
2. PL 拟合 BT mock 的当前 χ² 和参数分布与 PL 对照不同；该批链诊断未全部通过，不能据此声明已确证偏置显著性或排除 PL。
3. 当前链样本可以复算描述统计。6 维普通 split 统计最大 1.0535，8 维最大 1.5125；完整收敛与后验一致性验收尚未建立。
4. 旧 exact/emulator 比较报告 <0.25σ 中心差，但不能代替对最新链的验证。

## 5. 论文验收要求

- 每个数值指向冻结产物；当前可复算链数据使用 `paper/validate_draft_snapshot.py` 和对应 JSON。
- 预先确定误差和推断验收要求。实测 IC 散布不自动改变阈值；后验中心接近不自动说明分布一致。
- 分开报告普通 split monitor、独立链诊断和 ESS，避免把相互作用 walkers 当独立链。
- 模型比较采用相同观测量、指标、参数域和验证样本定义。
- 保留必要的 IC、chain、预测目标及可用性说明，每处限制放在所影响的结果附近。

## 6. 后续安排

先核对运行配置与 frozen metrics，再开展 exact 对照、IC 目标验证及充分采样。数据规模和链长更新必须附快照日期；不将历史预算或预计完成时间写成已实现的结果。

# Academic-v3 scientific figures

The thirteen reproducible figures share a white field, STIX typography, deep-blue/teal density shading and restrained vermilion/ochre comparison colours. Lighter spines, clearer marker weights, consistent legends and a compact upper-triangle information key improve visual hierarchy. Diagonal histograms retain the original data and bins. Heatmap colours remain square-root counts with per-panel normalization. No smoothing, sample selection, refitting or new probability contours were introduced.

All original input values, retained chain rows, statistical summaries, LF membership and prediction arrays are preserved. Numerical checks and output hashes are in ACADEMIC_V3_FIGURE_CHECKS_20261104.json. The source-only mock raster remains a historical reference because its matrix is not available for scientific reconstruction.

The offline HTML gallery provides thirteen figures, category filtering, full-resolution viewing and vector PDF downloads. The existing results pages use matching colours and corner assets. Physics v0.20 and methods v0.8 include the redesigned vector figures.

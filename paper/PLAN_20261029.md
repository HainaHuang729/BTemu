## 2. 与 Park et al. 2019 那类 emulator 论文的差距

| 论文要素 | 当前状态 | 缺口 |
|---|---|---|
| 训练集规模与设计 | 单 IC v2：train 82,860 / 100,000；validation 1,728 / 10,000 | validation 远未齐；sealed 未生成 |
| 模型收敛/验收 | R̂：6 维 1.08–1.11、8 维 1.28–1.75 | **未收敛**，无法作为论文主结果 |
| 精度表（τ/xHI/轨迹/ΔlogL） | 65k 已有：轨迹 RMSE 中位 0.0010、xHI q90 0.0079、τ q90 0.00070、ΔlogL q90 2.44 | ΔlogL 未过 0.1；需改为相对噪声或后验判据 |
| 与 exact 的后验一致性 | 已有：中心偏移 <0.25σ、宽度比 0.85–1.09 | 链长不足（exact 200 步、emu 2000 步），相关矩阵不可靠 |
| 基线对比 | Direct ResMLP vs NNERO 风格（0.0072 vs 0.027 中位） | 缺 21cmEMU/Park 风格基线的同口径对比 |
| 不确定度 | 未建模 | 需要 mean+σ 或 ensemble 报告 |
| 公开数据/代码 | 有仓库与契约 | 需发布 URL、版本、许可证 |

## 3. 建议的论文骨架（LaTeX）

1. Introduction：21cm 推断需要快速代理；BT 修改功率谱带来的 kp/ms 维度是现有 emulator（21cmEMU 等）未覆盖的。
2. Simulation & data：selected BT-21cmFAST、32 节点 xHI history、随机 IC 设计、Sobol 采样、冻结契约与验收流程。
3. Emulator：10 维输入 ResMLP（10→32），5 seed 集成；损失为物理 xHI MSE；训练规模 65k–100k。
4. Validation：轨迹/τ/xHI 分位误差、分区域（transition/low/high）误差、与 NNERO 风格基线对比、与 21cmEMU 口径对比。
5. Downstream：后验一致性（exact vs emulator）、IC 噪声标定（0.948 底）、ΔlogL 判据的讨论与替代。
6. Discussion：盒子尺寸与 IC 散射、kp/ms 联合采样的可行性、局限（未收敛、validation 不足）。
7. Data/code availability：仓库、契约哈希、复现命令。

## 4. 论文前必须补齐的实验（按优先级）

1. **收敛**：6 维与 8 维链跑到 R̂<1.05（当前在跑，预计今晚）。
2. **validation 补齐**：至少 2,000–5,000 条，覆盖窄区与过渡区。
3. **统一验收口径**：把 ΔlogL 换成“相对 IC 噪声”或后验一致性，写进方法。
4. **基线对比**：同数据、同验证集下比较 Direct ResMLP / NNERO / 21cmEMU（若能取到其预测）。
5. **不确定度**：ensemble 标准差或异方差头，给出覆盖率检验。
6. **学习曲线**：16k→26k→32k→65k→100k 的误差曲线（现有 16k/26k/32k/65k 已可出图）。

## 5. 时间估算（不含写作）

- 收敛：1–2 天（在跑）。
- validation 到 5k：按当前交替速率约 3–5 天（受组内节点共享限制）。
- 基线对比与不确定度：2–3 天开发 + 数小时训练。
- 图与表制作：1–2 天。

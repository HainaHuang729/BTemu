# 两篇论文的分工与执行顺序

日期：2026-10-29。物理稿 v0.10；BTemu 方法稿 v0.1。原 v0.9 单篇主线已由本分工取代。

## 1. 物理论文：BT 谱与再电离的联合推断

中心问题：允许星系物理参数变化后，再电离观测是否仍包含可辨认的 BT 谱信息？

主文围绕 MCMC 的物理结果组织：
- 模型、观测选择、实际先验与 likelihood 定义。
- 固定 astrophysics 的历史对比，作为解释采样结果的物理背景。
- 各谱独立拟合的 LF 网格与曲线。
- 六维固定谱和八维 galaxy+kp/MS 的样本汇总；八维完整分布放正文，六维及技术留样说明放附录。
- 哪些退化、边界或采样问题限制解释；待有合格链后再写观测组合、物理约束和预测。

BTemu 在正文只承担计算方法的说明。训练、架构、误差分布和 IC 方法分析不再作为物理论文的平行主线。附录保留解释 MCMC 所需的最小近似核查，不能因为分稿而删去可信度依据。

当前所有链仍按原诊断解释，不能把经验样本标准差改称已接受的可信区间。不能仅凭 corner 图给出谱探测或排除结论。

## 2. BTemu 方法论文：历史近似如何支持可靠推断

拟研究问题：随机初始条件和 BT 谱变化共同存在时，如何评估历史近似是否足以保持目标推断？

现有可写结果：
- BT 输入谱和十维物理支持域、32 节点 volume-mean 历史的明确任务定义。
- ResMLP 和五模型物理输出平均的实际验证规则。
- 512 条 development-validation 的逐模型及平均预测误差。
- exact 200 步与 emulator 的有限样本比较及其限制。
- 已有重复 IC 审计、代表历史与 IC 边缘化目标的区别。

仍需形成的独立证据：
- 冻结部署模型的独立最终测试和派生 likelihood 误差。
- 重复 IC 的均值不确定度与预测误差分离。
- 定量判断代表历史近似何时足够、何时改变推断；如需额外处理，提出并验证该处理。
- 相同目标、先验及后处理下独立收敛的 exact/emulator 推断与观测量预测比较。
- 完整 likelihood 的端到端成本和可复用发布。

目前方法稿是一份可继续补证据的独立工作稿，不代表独立新意或科学部署已经完成。

## 3. 与既有文献的关系及新意判断

| 内容 | 定位 |
|---|---|
| 用 emulator 加速再电离推断 | 已有先例，不能作为独立新意 |
| 改用 ResMLP、增加训练样本或五模型平均 | 实现和验证选择，本身不建立方法贡献 |
| 随机 IC 训练 | 21cmEMU v3 已包含不同 IC 的模拟，不应宣称首次 |
| exact 与 emulator 的推断对照 | 较早的 21cmEMU 已进行，属于必要验证 |
| BT 谱参数域的公开可复用近似 | 有应用/资源价值，需明确适用域和完整验证；不自动等于算法创新 |
| IC、历史误差和 likelihood 目标如何共同影响 BT 推断，以及经验证的处理 | 可发展的独立方法问题；当前尚未完成，不能预写成贡献 |

对照文献：
- 21cmEMU：https://arxiv.org/html/2309.05697v2
- 21cmEMU v3：https://arxiv.org/html/2606.00219v1

以上不是穷尽性新颖性检索；在提出“首次”或“优于既有方法”的主张前仍需专门检索和同口径比较。

## 4. 图和证据的归属

| 材料 | 主要归属 | 另一篇如何使用 |
|---|---|---|
| BT/PL 历史、LF 网格及拟合曲线 | 物理论文 | 方法稿不复用为算法验证结果 |
| 联合 kp/MS MCMC 与物理解释 | 物理论文 | 方法稿仅在明确目标匹配后作为推断验证 |
| 训练、逐 seed/平均预测误差、独立最终测试 | 方法论文 | 物理论文保留简短方法说明和必要指标 |
| 重复 IC 与 likelihood 目标分析 | 方法论文 | 物理论文必须说明实际采用的目标及其局限 |
| exact/emulator 数值比较 | 方法论文的近似验证；物理论文的可信度依据 | 明确是同一实验，不能当作两个独立结果 |
| PL→PL、BT→BT、BT→PL mock 恢复 | 物理论文的模型错设检验 | 方法稿可引用验证依据，不重复包装科学发现 |

全部原有表中数值、科学公式、引用和 11 个图资产均在两稿中保留。物理稿使用 10 个图资产，方法稿使用 4 个，其中 3 个共享输入图是同一批证据，不是独立实验。未重新绘图或新增统计结果。

## 5. 两份稿件入口

Overleaf 项目继续使用同一个项目，避免迁移已有资料：
- 物理主文：paper/main.tex。
- BTemu 方法稿：paper/btemu_methods/main.tex。
- 方法稿正文：paper/btemu_methods/body.tex。
- 分稿核对：paper/revisions/PAPER_SPLIT_CHECKS_20261029.json。

默认 Overleaf 主文保持物理论文。方法稿可在本地独立编译，或在 Overleaf 明确选择它为主文后查看；不要因方法稿存在就误编译替换物理主文。

## 6. 接下来先补什么

1. 配置、实际先验、部署 predictor、native 与 likelihood 对齐。
2. 物理推断所需的最小可信度验证：独立测试、合格 exact 参考、IC 目标核验。
3. 独立收敛的物理链、正确模型 mock 恢复及观测组合/预测。
4. 根据 IC/误差研究是否形成独立结果，决定方法论文的最终贡献与投稿范围。

物理论文不必等待方法论文先发表，但必须已有可检查的数值可信度依据。若 BTemu 最终仅是标准网络在 BT 域的应用，则可保留为工具、技术材料或物理论文附录，不为拆成两篇而扩张新意。

完整材料需求沿用 [优先级清单](MISSING_MATERIALS_PRIORITIZED_20261029.md)；分稿改变叙述和归属，不取消任何尚未完成的科学核查。

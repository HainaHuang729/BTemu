# Contour refinement

Three variants refine the selected lower-triangle contour direction: lines, light wash (recommended), and layered bands. All five source corner figures are included. In-figure information blocks, titles, legends and colourbars are absent.

All stored retained rows contribute to 32-bin 1D histograms and 32-by-32 2D histograms. The preview uses Gaussian display smoothing: sigma 0.8 bins (1D), 1.1 bins (2D), reflect boundary mode. Contours are panel-peak-relative density levels: 0.10, 0.35, 0.70 for lines and light wash; 0.10, 0.32, 0.60, 0.82 for layered bands. They are not probability-content regions. The historical diagonal groups retain separate blue and ochre curves.

Original sample selection and coordinate limits are unchanged. Input hashes, renderer hash, output hashes and per-panel counts are in manifest.json. Every output passed label extent checks. The manuscript assets remain the accepted earlier version while the contour presentation is refined. Open index.html for comparison.

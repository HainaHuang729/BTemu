# Single-layer corner fill

Each data set has one translucent filled density band and one outline level. The current preview uses the previous outer level: 10% of each panel peak smoothed bin count; it is not a probability-content contour. Fill alpha is 0.18; diagonal marginal alpha is 0.12. Histograms use all retained rows and 32 bins, with unchanged display smoothing (sigma 1.1 bins in 2D, 0.8 in 1D).

Five archived corner cases are included. Source hashes and per-panel counts were checked; no second data set has been added. The second data set must be identified before an actual overlay is produced. No figure information blocks or legends are added. The accepted manuscript assets remain unchanged.
